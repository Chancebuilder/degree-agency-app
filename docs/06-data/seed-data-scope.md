# Seed data scope

8 Tier A institutions, 51 bachelor's programs, 15 providers, 239 credit opportunities, 1,691 requirement slots, 603 policy rules, 8,125 equivalencies. Generated by `scripts/generate_seed.py` plus `scripts/seed_extensions.py`. Last verified `2026-09-01`.

Tuition, residency, and ACE/PLA posture cite official pages and are marked VERIFIED. Equivalency rows are compiled from published transfer posture plus ACE National Guide, NCCRS exhibits, and common course codes. They are **not** registrar extracts.

## Degree families

| Family | Typical bachelor's titles in seed |
|---|---|
| Business Administration | BSBA / BBA at every seeded school |
| Psychology | YourPace, WGU, TESU, Excelsior, Charter Oak, SNHU, UMass Global, Purdue Global |
| General Studies | TESU BA Liberal Studies, Excelsior BS Liberal Arts, Charter Oak BS General Studies, SNHU BA General Studies, UMass Global BA Applied Studies, Purdue Global BS Professional Studies, UMPI Liberal Studies |
| Healthcare Management | UMPI, WGU, TESU Health Services, Excelsior Health Sciences, Charter Oak, SNHU, Purdue Global |
| Cybersecurity | Existing cyber / MyPath IT paths |
| Software Engineering | WGU Software Engineering, Charter Oak Software Development, SNHU Computer Science, TESU/Excelsior/PG IT (closest published path) |
| Criminal Justice | UMPI, TESU, Excelsior, Charter Oak, SNHU, UMass Global, Purdue Global |

WGU does not publish a criminal justice bachelor's, so it does not appear in that lane. UMass Global MyPath does not publish psychology or criminal justice CBE programs; those two UMass rows are the school's term-based online bachelor's.

## How to regenerate

```bash
python3 scripts/generate_seed.py
```

Restart the API so `SeedLoader` upserts by stable UUID.
