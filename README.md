# Degree Dean by The Degree Agency

Adult learners already have leverage. Degree Dean turns prior college credit, exams, and alternative credit into an honest remaining path at transfer-friendly schools.

The Degree Agency is **not** a college, accreditor, registrar, or degree-granting institution. Every credit total, cost, and completion date in this product is an estimate. Final authority rests with the receiving institution.

**Don’t start over. Start strategically.**

## What this MVP does

One student can complete the first working journey:

1. Create an account (email + password, Argon2id, JWT + rotating refresh)
2. Confirm they are 18 or older
3. Accept purpose-specific consent and the product disclosure
4. Create a profile
5. Choose Business Administration, Psychology, General Studies, Healthcare Management, Cybersecurity, Software Engineering, or Criminal Justice at a Tier A school
6. Import a CSV/TSV/TXT transcript that is parsed in the browser
7. Review and verify each course
8. Save a structured Academic Wallet (the original file never uploads)
9. Run deterministic equivalency matching: applied, surplus with reasons, unapplied
10. Simulate Fastest, Cheapest, and Best Fit
11. See a Next Best Action

Admin users can inspect policy rules, update them with an audit trail, and review the stale-data queue.

## Local run

Requires Java 21, Maven, Node 22, and PostgreSQL 16.

```bash
# database
sudo pg_ctlcluster 16 main start   # or: docker compose up -d postgres
createdb degree_dean               # already created in the cloud environment

# API
cd apps/api
mvn spring-boot:run

# web
cd apps/web
npm install
npm run dev
```

- Web: http://127.0.0.1:18427
- API: http://127.0.0.1:18428/api/v1
- OpenAPI: http://127.0.0.1:18428/api/v1/docs

Copy `.env.example` if you need to override defaults. Do not commit secrets.

### Sample student

1. Register any email and a password of 10+ characters
2. Use date of birth `1988-04-12` on the age gate
3. Accept the three required consents
4. Import [`data/seed/sample-transcript.csv`](data/seed/sample-transcript.csv) (also served from `/sample-transcript.csv`)

### Local admin

`dean@thedegreeagency.com` / `ChangeMeNow!` — change this before any shared environment.

## Seed data

Version-controlled CSVs in [`data/seed/`](data/seed/), generated by [`scripts/generate_seed.py`](scripts/generate_seed.py) and loaded idempotently at API startup.

| Set | Count |
|---|---|
| Institutions (Tier A) | 8 |

| Requirement slots | 1,691 |
| Policy rules | 603 |
| Providers | 15 |
| Credit opportunities | 239 |
| Equivalencies | 8,125 |

Tuition and transfer figures cite official pages. Equivalency rows are compiled from those institutions’ published transfer posture plus common ACE-provider course codes. They are **not** a guarantee of current registrar practice. See [`docs/06-data/data-collection-runbook.md`](docs/06-data/data-collection-runbook.md).

## Architecture

Modular monolith:

- `apps/web` — React, TypeScript, Vite, Tailwind
- `apps/api` — Java 21, Spring Boot, Flyway, PostgreSQL
- `modules/` — domain boundary notes for later extraction
- `infrastructure/` — Docker, GitHub Actions, Terraform for Azure Container Apps

Matching is table lookup only. Policy is data. Simulator constants live in `application.yml`. There is no AI dependency.
