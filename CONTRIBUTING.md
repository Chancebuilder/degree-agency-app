# Contributing

1. Read `docs/01-product/mvp-scope.md` before adding a feature.
2. Do not move a module between Class 1 / 2 / 3 without an ADR.
3. Academic rules are data. Add CSV rows or use the admin console.
4. Never present an unverified equivalency to a student.
5. Run `mvn test` and `npm test` before opening a change.

See `docs/10-developer-guide/contribution-guide.md`.
